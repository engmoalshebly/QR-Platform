# Qentry Field PWA

التطبيق الميداني المعزول لمسّاحي البوابات. لا يعرض لوحة المؤسسة أو الفريق، ويعمل فقط عبر وردية وبوابة وجلسة جهاز صالحة.

## التشغيل المحلي

```powershell
cd D:\QR\field-pwa
npm install
npm run dev
```

افتح `http://localhost:5174/field/`. خادم Vite يمرّر `/api` إلى FastAPI المحلي.

## الإنتاج

نفّذ `npm run build`. يخدم FastAPI المجلد `dist` حصراً من `http://<api>/field/`، مع سياسة تسمح بالكاميرا لهذا المسار وحده. لا تنشر `dist` على جذر لوحة الإدارة.

الحزم المحلية وطابور المسحات وجلسة الجهاز مشفّرة في IndexedDB بمفتاح Web Crypto غير قابل للاستخراج؛ لا تحتفظ الحزمة باسم أو هاتف أو بريد الضيف، ولا تستعاد الجلسة إلا للحساب نفسه في مساحة الفريق ذاتها.
