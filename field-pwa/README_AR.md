# Qentry Field PWA

تطبيق جوال أولاً، مستقل عن لوحة المؤسسة والفريق، لموظفي البوابات المكلّفين بورديات معتمدة فقط.

## الموجود الآن — مراحل 0 إلى 2

- تسجيل دخول فردي ثم اختيار **فريق التشغيل** فقط؛ لا تظهر مساحات المؤسسة في هذا التطبيق.
- عرض «حفلاتي وبواباتي» حسب اليوم من `GET /api/v1/mobile/shifts?date=`.
- بدء جلسة جهاز مرتبطة بورديّة وبوابة، وحفظ سر الجلسة في `sessionStorage` فقط.
- إغلاق الجلسة وتسليم البوابة عبر الواجهة الخلفية الموثقة.
- تطبيق قابل للتثبيت: manifest وservice worker. لا يخزن service worker أي استجابة API أو بيانات ضيوف.

لا توجد شاشة ماسح أو بيانات دعوات أو وضع دون اتصال بعد. هذه مقصودة؛ إذ تبدأ عند المرحلة الثالثة بعد توحيد تحليل QR في الخادم، ثم تضاف حزمة الوردية المشفرة والطابور الآمن في المرحلة الخامسة.

## التشغيل المحلي

```powershell
cd D:\QR\field-pwa
npm install
npm run dev
```

يعمل على `http://localhost:5174` ويحوّل `/api` إلى FastAPI محلياً على المنفذ `8021`.

## حدود الأمان

- معرّف الجهاز غير حساس ويحفظ محلياً لإثبات الجهاز نفسه فقط.
- رموز الدخول ورمز جلسة البوابة لا تحفظ إلا في `sessionStorage` وتنتهي بإغلاق جلسة المتصفح أو تسجيل الخروج.
- لا تضع أي مفتاح خدمة أو مفتاح توقيع QR ضمن `VITE_*`؛ جميعها تصبح عامة داخل حزمة المتصفح.
- لا يعد التطبيق جهازاً مسموحاً بالمسح من تلقاء نفسه؛ الخادم يفرض الدور، عضوية العملية، الوردية، البوابة، وجلسة الجهاز في كل طلب.
