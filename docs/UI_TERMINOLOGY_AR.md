# دليل مصطلحات الواجهة

التسميات العربية المعتمدة تنطبق على العناوين والأزرار والصلاحيات ورسائل الخطأ. تبقى مفاتيح API والصلاحيات وحالات قاعدة البيانات كما هي.

| المعنى | التسمية المعتمدة |
|---|---|
| Event | المناسبة؛ الجمع المناسبات |
| Generation | إنشاء الدعوات |
| Generation history | عمليات إنشاء الدعوات |
| Final invitations | الدعوات الجاهزة للدخول |
| Event templates | تصاميم الدعوات |
| Dynamic text | بيانات متغيرة، مثل اسم الضيف ورقم الطاولة |
| QR for entry | رمز الدخول QR |
| Workspace members | أعضاء الفريق |
| Workspace invitations | دعوات الانضمام للفريق |
| RSVP navigation | ردود الضيوف |
| RSVP feature | تأكيد الحضور |
| Public registration | التسجيل في المناسبة |
| Gate scan | تسجيل الدخول |
| Print layout | إعدادات الطباعة |
| WhatsApp unknown | نتيجة الإرسال غير مؤكدة |

أكد الحضور = وافق الضيف. تم قبول الطلب = وافق المنظم على طلب التسجيل. تم تسجيل الدخول = سُجل الوصول عند البوابة. لا تُستبدل هذه الحالات ببعضها.

تم الإرسال يختلف عن تم التسليم وعن تمت القراءة؛ تتبع التسميات نتيجة مزود الإرسال الفعلية. دعوة الانضمام للفريق تختلف عن دعوة الضيف.

يبقى «مساحة العمل» عند اختيار بيئة الإدارة، وتُستخدم بيانات الجهة/المؤسسة لوصف المالك القانوني أو الاشتراك؛ لا يدمج هذان المفهومان باستبدال شامل.

تغيير الأسماء الظاهرة لا يعيد تسمية مناسبات العملاء أو تصاميمهم أو رسائلهم المحفوظة. يحتفظ محرر التصميم بالتعرف على تسمية «نص ديناميكي» القديمة إلى جانب «بيانات متغيرة».
