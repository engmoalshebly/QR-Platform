# من الداشبورد إلى إرسال نص أو صورة عبر API

## 1. اربط رقم المرسل

1. افتح [الداشبورد](https://notify.prideidea.com/dashboard) وسجل الدخول بمفتاح إدارة OpenWA.
2. من **Sessions ← New Session** أنشئ جلسة، ثم اضغط **Start**.
3. من واتساب الهاتف: **الأجهزة المرتبطة ← ربط جهاز**، ثم امسح QR المعروض.
4. انتظر **Connected**، وافتح تفاصيل الجلسة وانسخ **Session ID**. تحقق من رقم المرسل المعروض.

إذا كانت جلستك متصلة بالفعل، استخدمها مباشرة دون إنشاء جلسة أخرى.

## 2. احصل على API Key

من **API Keys ← Create API Key** أدخل اسماً، واختر الدور **operator**، ثم أنشئ المفتاح وانسخه كاملاً عند ظهوره. لا تستخدم `Key Prefix` المختصر.

نافذة إنشاء المفتاح الحالية لا تقيده بجلسة واحدة؛ لإصدار مفتاح مقيد اتبع [الخطوة الثانية في دليل الربط](OPENWA_SEND_AFTER_DASHBOARD_AR.md#2-جهز-مفتاحا-خاصا-بهذه-الجلسة). احتفظ بالمفتاح على خادم نظامك، ولا تضعه في كود المتصفح أو Git.

## 3. جهز Postman

اختر **POST**، ثم أضف في **Headers**:

| الاسم | القيمة |
|---|---|
| X-API-Key | المفتاح الكامل من الخطوة السابقة |
| Content-Type | application/json |

في الأمثلة التالية استبدل:

- `SESSION_ID`: معرّف الجلسة من تفاصيل الداشبورد، وليس اسم الجلسة أو رقم الهاتف.
- `RECIPIENT_NUMBER`: رقم المستلم الدولي بالأرقام فقط دون `+` أو مسافات، مثل رمز البلد ثم الرقم.

**تنفيذ الطلب يرسل رسالة فعلية؛ اختر رقم تجربة مقصوداً.**

## 4. تجربة إرسال نص

**الرابط:**

```text
https://notify.prideidea.com/api/sessions/SESSION_ID/messages/send-text
```

**Body ← JSON:**

```json
{
  "chatId": "RECIPIENT_NUMBER@c.us",
  "text": "مرحباً، هذه رسالة اختبار من النظام."
}
```

اضغط **Send**. النص مطلوب وبحد أقصى **4096 حرفاً**.

## 5. تجربة إرسال صورة مع نص

استخدم **POST** والرؤوس نفسها، وغيّر الرابط إلى:

```text
https://notify.prideidea.com/api/sessions/SESSION_ID/messages/send-image
```

**Body ← JSON:**

```json
{
  "chatId": "RECIPIENT_NUMBER@c.us",
  "url": "https://your-domain.com/image.jpg",
  "caption": "مرحباً، هذه صورة مرفقة برسالة اختبار."
}
```

استبدل `url` برابط HTTPS مباشر لصورة يمكن للخادم تحميلها دون تسجيل دخول، ثم اضغط **Send**. النص المرفق بالصورة يوضع في **caption** وبحد أقصى **1024 حرفاً**، ويصل مع الصورة في رسالة واحدة.

## 6. تأكد من النتيجة

استجابة النجاح تتضمن:

```json
{
  "messageId": "provider-message-id",
  "timestamp": 1792470000
}
```

احفظ `messageId` وتحقق من وصول النص أو الصورة على هاتف المستلم. استجابة الإرسال وحدها لا تؤكد التسليم أو القراءة؛ تأكيدهما آلياً يحتاج Webhook.

| المشكلة | الحل |
|---|---|
| `Cannot GET .../send-text` أو `send-image` | غيّر الطريقة من GET إلى POST |
| `401` أو `403` | تحقق من المفتاح الكامل ودوره وقيد الجلسة إن وجد |
| `404` مع POST | تحقق من الرابط وSession ID |
| الجلسة غير جاهزة | انتظر Connected أو أعد الربط عند الحاجة |
| فشل تحميل الصورة | استخدم رابط صورة مباشر يمكن للخادم الوصول إليه |
| مهلة أو انقطاع أثناء الإرسال | راجع النتيجة قبل التكرار؛ قد تكون الرسالة خرجت بالفعل |

هذه الأمثلة تستخدم **OpenWA المباشر `/api`**، ولا توفر منع التكرار الخاص بخدمة الإشعارات `/v1`. خدمة `/v1/notifications` الحالية تدعم النصوص فقط.
